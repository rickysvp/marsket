# 竞界 · 多品类互动原型

独立的 React/Vite 网页原型，依据对参考站的页面结构与交互观察制作。所有品牌、赛事、赔率、奖池、游戏画面及账户信息均为原创演示数据；不连接真实投注、支付、直播或第三方游戏服务。

## 本地运行

在项目根目录中运行：

```bash
npm ci
npm run dev
```

然后打开 [http://127.0.0.1:5173/sports](http://127.0.0.1:5173/sports)。

检查命令：`npm test`、`npm run build`。

## 页面范围

- 体育首页、七种体育列表、直播目录、赛事详情与演示选择单
- 电竞项目赛程、真人桌台、棋牌与捕鱼、老虎机、奖池、彩票示意
- 游戏承载页、账户和记录

彩票原站内容未能核实，因此此原型仅有栏目和待核实状态。详情见 [`docs/qa.md`](docs/qa.md)。
